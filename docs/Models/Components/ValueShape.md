# ValueShape

Shape the comparison value must have: `scalar` for a single value, `list` for a non-empty array of values (`in`, `not_in`), `none` for an operator that takes no value at all (`is_null`).


## Values

| Name     | Value    |
| -------- | -------- |
| `Scalar` | scalar   |
| `List`   | list     |
| `None`   | none     |
