# TaxCatalogIndirectRegime

An indirect tax regime determined by the territory the issuer operates from (IVA on the mainland and the Balearic Islands, IGIC in the Canary Islands, IPSI in Ceuta and Melilla). This is the "which tax applies" axis; it is orthogonal to the operation regime, which answers "how is this transaction taxed".
