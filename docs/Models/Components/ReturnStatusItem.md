# ReturnStatusItem

A return status from the closed catalog, with its label and its colour token. Returned by `GET /v1/companies/{company}/returns/statuses` as a flat list, without pagination. The three fields are DERIVED from the value object of the lifecycle and never from a hand-written list: a parallel list drifts at the first extension and the catalog starts publishing statuses that no longer exist. Unlike the delivery note, the return does NOT translate any internal status into a different public vocabulary: the catalog is the same on both surfaces.
