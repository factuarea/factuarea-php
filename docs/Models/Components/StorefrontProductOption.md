# StorefrontProductOption

One configurable option group of an item, with the values the buyer can choose from. What the buyer picks is a value of each group; the combination of all of them is what the selection resolution turns into an offerable item. A group whose values are all withdrawn is not published: an option nobody can choose is not an option.
