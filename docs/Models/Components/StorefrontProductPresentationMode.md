# StorefrontProductPresentationMode

How the presentation converts into base units: `fixed` (a closed format, a case of twelve) and `variable_measure` (a format measured at the till, loose weight). The mode is what tells apart a format whose content is known in advance from one that is weighed.


## Values

| Name              | Value             |
| ----------------- | ----------------- |
| `Fixed`           | fixed             |
| `VariableMeasure` | variable_measure  |
