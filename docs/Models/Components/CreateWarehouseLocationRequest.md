# CreateWarehouseLocationRequest

Create a location inside the warehouse in the path. `code` (required, up to 20 chars, letters, digits and hyphens, stored uppercase) is unique within its warehouse among the active locations; a duplicate is rejected with 422 naming the field, and archiving a location frees its code. `name` (required, up to 120 chars) is the human-readable label. `parent_id` (optional) is the public ID of the parent location, which must belong to the same warehouse; omit it for a top-level location. The hierarchy is one level deep: naming a parent that already has a parent is rejected with 422 as a business rule violation, not as a malformed body. The warehouse comes from the path and the location ID is assigned by the operation; neither is accepted in the body.
