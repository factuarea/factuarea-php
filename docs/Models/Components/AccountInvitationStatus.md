# AccountInvitationStatus

Derived state. `accepted` and `canceled` are final; `expired` only applies to an invitation that was still pending when its expiry passed.


## Values

| Name       | Value      |
| ---------- | ---------- |
| `Pending`  | pending    |
| `Accepted` | accepted   |
| `Canceled` | canceled   |
| `Expired`  | expired    |
