# BulkPartialSuccessResultFailure

A failed row/resource. Identity is polymorphic: `id` for an existing resource (bulk-delete/bulk-send/bulk-pdf), or `index` for a new row without a resource yet (bulk-create with `dry_run`, import CSV). Exactly one of `id`/`index` is present.
