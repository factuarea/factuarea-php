# BulkDeletePurchaseOrdersRequest

Delete several purchase orders in one request. `ids` is an array of 1 to 100 purchase-order UUIDs. Unknown identifiers, identifiers of another company and orders that cannot be deleted in their current state — one with goods already received, or already billed by the three-way match — are reported as failed one by one, rather than failing the whole request. Deleting is irreversible: an order does not come back, and creating it again produces a different one, with a different id and a different number.
