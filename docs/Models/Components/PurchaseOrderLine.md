# PurchaseOrderLine

A line of a purchase order. It is the only line of the API that carries TWO units at once: the PURCHASE unit that was agreed with the supplier (a box, a pallet) and the BASE unit of the catalog item, joined by the conversion factor frozen on the line. Everything that later enters the warehouse is measured in the base unit, and everything the supplier invoices is measured in the purchase unit, so both travel side by side instead of being recomputed on each screen.
