# PurchaseInvoiceMatch

The three-way match of a supplier invoice, read from the INVOICE: the resulting status, the purchase order it is linked to, and line by line what was ordered, what was received and what is being invoiced, with the typed reason of every deviation and the figure that justifies it. It is what the three match write operations return, so the integrator sees the resulting state without a second call.
