# ManagedAccountStatus

Status of the ACCOUNT: `provisioned` (created by you, not claimed yet), `claimed` (its holder took it) or `active`. The end of the management is read in `management`, not here.


## Values

| Name          | Value         |
| ------------- | ------------- |
| `Provisioned` | provisioned   |
| `Claimed`     | claimed       |
| `Active`      | active        |
