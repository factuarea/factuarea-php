# AccountWebhookAccountRelationship

Whose tax IDs the endpoint hears about: `own` (the tax IDs of your account), `managed` (the accounts your account manages) or `all` (the default).


## Values

| Name      | Value     |
| --------- | --------- |
| `Own`     | own       |
| `Managed` | managed   |
| `All`     | all       |
