# ManagedAccountImportRowMode

`managed_account` provisions a separate account for a client; `own_nif` registers the tax ID as an additional tax ID of YOUR account. `null` when the row does not carry a valid `mode` (the row is `ERROR`).

| Name             | Value            |
| ---------------- | ---------------- |
| `OwnNif`         | own_nif          |
| `ManagedAccount` | managed_account  |
