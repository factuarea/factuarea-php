# StartConnectedAccountAuthorizationV1Request

Start the Stripe Connect authorization of a company. `return_url` is required: an absolute `https` URL (up to 2048 characters, no credentials, no fragment, port 443 or none) whose host is one of the return domains of the account of the credential. Any other key in the body or the query returns 400 `parameter_unknown`.

Its host must be one of the return domains of the account of the credential, otherwise the request returns 422 `connect_return_url_not_allowed`. Factuarea appends these query parameters on the way back: `status` (`success` or `error`), `provider` (always `stripe`) and `authorization_id` always; on success also `company_id` (the company `id`, UUID v7), `connected_account_id` and `account`; on error also `error` and, when there is one, `error_subcode`. |
