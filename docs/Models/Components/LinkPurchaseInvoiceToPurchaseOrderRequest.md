# LinkPurchaseInvoiceToPurchaseOrderRequest

Link this purchase invoice to a purchase order and evaluate the three-way match right away. The body carries ONE property, `purchase_order_id`: the public identifier of the order to match against, which has to belong to the same company as the invoice — one from another company answers not found, exactly like one that does not exist. Only an order that has already received goods can be matched, and an invoice that is linked already is rejected as a business-rule violation instead of being relinked. The response carries the resulting match, including the per-line deviation detail, so the outcome needs no second call.
