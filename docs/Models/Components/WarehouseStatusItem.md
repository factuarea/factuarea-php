# WarehouseStatusItem

A warehouse status from the closed catalog, with its label and what it allows. Returned by `GET /v1/companies/{company}/warehouses/statuses` as a flat list. The permissions are ANSWERED by the state machine of the domain, never copied into a hand-written list, so a status that changes what it allows changes it here too.
