# StorefrontBuyerOrderWithContact

The order of the buyer right after completing their fiscal identity, plus the reference of the business contact that completion promoted. It is the SAME eleven keys of the order —so a storefront can paint the updated order without asking for it again— with one more that only this operation emits: a buyer who now carries a fiscal identity becomes a business contact of the seller, reused by tax id when it already exists, and the reference says which one so the storefront can name it.
