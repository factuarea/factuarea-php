# ReturnRejectionReason

Why the return was rejected, out of a closed catalog: `window_expired` and `exceeds_delivered` are the two AUTOMATIC ones and `manual_decision` is the one a person takes. `null` while the return has not been rejected.


## Values

| Name               | Value              |
| ------------------ | ------------------ |
| `WindowExpired`    | window_expired     |
| `ExceedsDelivered` | exceeds_delivered  |
| `ManualDecision`   | manual_decision    |
