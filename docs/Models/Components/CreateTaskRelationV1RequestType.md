# CreateTaskRelationV1RequestType

Relation type: `subtask` (the target task is a subtask of the task in the path), `blocks` (the task in the path blocks the target task) or `related`.

| --------- | --------- |
| `Subtask` | subtask   |
| `Blocks`  | blocks    |
