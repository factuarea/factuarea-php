# ReturnCorrectiveCandidate

An invoice that the refund of a return could correct. It is the second PRE-FLIGHT read: the refund resolves the target invoice on its own when there is EXACTLY ONE candidate, rejects when there is none and rejects as AMBIGUOUS when there are several without a choice — and this operation is the question that answers which ones they are, so the client can pick one and send it. A return with no candidate returns the EMPTY collection and not an error: an empty collection is the right answer to a legitimate question, and the rejection belongs to the refund.
