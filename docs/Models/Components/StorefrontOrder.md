# StorefrontOrder

The order placed from the shop window. It is the SAME sales order the merchant works with afterwards, published with what the buyer is allowed to see: no price list, no margin, no supplier and no internal note. Placing it is NOT irreversible —an order can be cancelled— but it is the point where the cart stops being editable, so what it publishes is what the buyer agreed to: their identity, their lines with the amount the server froze, and their totals.
