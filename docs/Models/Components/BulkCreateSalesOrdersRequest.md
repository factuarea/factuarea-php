# BulkCreateSalesOrdersRequest

Create sales orders in bulk. `sales_orders[]` holds up to 100 sales-order payloads, each with the same shape as the single-create body. Per-row rules (format, unknown company references, an `external_id` already taken) are reported per row under `failures[]` instead of failing the whole batch. Every created order consumes monthly plan quota: when the remaining quota is smaller than the batch, the orders that do not fit are reported as failed with the quota code and the rest are created.
