# AccountWebhookDelivery

The delivery of ONE event to ONE account webhook endpoint: which event, about which tax ID, with which relationship to your account, in which state, how many attempts it took, what your server answered and the signed envelope that was sent. Unlike a company delivery, a manual retry re-arms this same delivery instead of creating another one.
