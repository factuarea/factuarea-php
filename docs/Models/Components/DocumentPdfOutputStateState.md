# DocumentPdfOutputStateState

Revisioned PDF output state, or `null` when the document has no retained output state.


## Values

| Name          | Value         |
| ------------- | ------------- |
| `Prepared`    | prepared      |
| `Queued`      | queued        |
| `Processing`  | processing    |
| `Ready`       | ready         |
| `Failed`      | failed        |
| `Unavailable` | unavailable   |
| `Corrupt`     | corrupt       |
