# CreateReturnRequestOriginType

Kind of document the goods came out on: `delivery_note`, `invoice` or `sales_order`. It says where the returnable quantities are read from, and it is not redundant with the identifier: the three kinds are numbered independently.


## Values

| Name           | Value          |
| -------------- | -------------- |
| `DeliveryNote` | delivery_note  |
| `Invoice`      | invoice        |
| `SalesOrder`   | sales_order    |
