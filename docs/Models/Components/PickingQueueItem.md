# PickingQueueItem

One element of the WORK QUEUE of the warehouse: a delivery note with its picking open, seen from the shop floor. It is a deliberately THIN projection of the picking list — it carries no lines, no counts and no staleness indicator — because the queue is the screen that paints the most rows and resolving all that per row would be one query per line. Whoever picks one opens its picking list.
