# WarehouseType

Operational nature of the warehouse: `own` (a place of the company), `external` (a third party holding its goods), `store` (a point of sale) and `transit` (goods on their way between two of the above). It is a closed catalog and it does NOT change what the API lets you do with the warehouse: it classifies it.


## Values

| Name       | Value      |
| ---------- | ---------- |
| `Own`      | own        |
| `External` | external   |
| `Store`    | store      |
| `Transit`  | transit    |
