# UpdateSalesOrderShippingAddressRequest

Replace the SHIPPING address of a sales order. It touches only where the order is delivered and preserves the billing address, which belongs to the buyer identity and is changed with the buyer operation; that separation is what lets you fix the delivery of an already confirmed order without reopening who bought it. The body carries `shipping_address_line`, `shipping_city`, `shipping_province`, `shipping_postal_code` and `shipping_country`. The country is a two-letter code and becomes required as soon as any other field is sent, because an address with no country can neither be delivered nor validated. A body with every field empty CLEARS the shipping address, and that is how you say the order is picked up at the shop: a sales order is allowed to have no delivery address. An order whose status no longer allows editing rejects this operation as a business-rule violation.
