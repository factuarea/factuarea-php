# CreateAccountWebhookV1Request

Create a webhook endpoint of your ACCOUNT. Required: `url` (HTTPS, up to 2048 characters) and `enabled_events` (at least one type: the company events of the public catalog and the `account.*` events of `AccountEventType`; an unknown, reserved or not released type returns 422 and nothing is created). Optional: `account_relationship` (`own`, `managed` or `all`, the default), `description` (up to 255 characters) and `api_version` (`YYYY-MM-DD`; the latest supported version when omitted). The environment is never a field: the endpoint is born in the environment of the credential and never changes it.
