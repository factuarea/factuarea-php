# UpdateSeriesRequestCounterReset

Counter reset policy: `never`, `annual` or `monthly` (`monthly` requires the `{MM}` token in the mask). Prospective change: numbers already issued are not renumbered.


## Values

| Name      | Value     |
| --------- | --------- |
| `Never`   | never     |
| `Annual`  | annual    |
| `Monthly` | monthly   |
