# AccentColor

Accepted format for the `accent_color` of the PDF.


## Fields

| Field                         | Type                          | Required                      | Description                   | Example                       |
| ----------------------------- | ----------------------------- | ----------------------------- | ----------------------------- | ----------------------------- |
| `format`                      | *string*                      | :heavy_check_mark:            | Expected hex format.          | #RRGGBB                       |
| `example`                     | *string*                      | :heavy_check_mark:            | A valid accent color example. | #1a73e8                       |
