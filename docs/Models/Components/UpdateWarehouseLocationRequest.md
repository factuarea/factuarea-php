# UpdateWarehouseLocationRequest

Partially update a location. Both `code` and `name` are optional and an empty body is a no-op; neither accepts null, since a location cannot be left without a code or a label. The code stays unique within its warehouse among the active locations, and resending the code the location already has is accepted. The warehouse is part of the location identity and cannot be changed, the parent location is declared when the location is created, and withdrawing a location has its own operation: all three are rejected if sent in the body.
