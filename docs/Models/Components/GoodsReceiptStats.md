# GoodsReceiptStats

Aggregated headline figures of the goods receipts of the authenticated company. Returned by `GET /v1/companies/{company}/goods-receipts/stats`, wrapped in `{ "data": GoodsReceiptStats }`. It carries no amount on purpose: this family counts units, not money.
