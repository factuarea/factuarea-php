# RegisterGoodsReceiptRequest

Register a goods receipt against a purchase order. A receipt is born as `created`: it is a written declaration with no effect yet — it consumes no pending quantity and does not move the order status; posting it is a separate operation. `purchase_order_id` is required when registering through the goods receipt resource and must be omitted — or repeated identically — when registering under the purchase order, where the order comes from the path. `lines` is required and needs at least one entry: an empty receipt is not a document. Each line names the purchase order line it consumes and the quantity received IN THE PURCHASE UNIT of that line; its base-unit equivalent is derived with the conversion factor the ORDER froze when the line was added, never with the one the catalogue holds today.
