# StorefrontRevalidation

The answer to "is my cart still valid?": the cart already brought up to date plus the verdict line by line. It carries the WHOLE cart —with the same shape its own read has— so the shop window can carry on without a second call, which is what makes it usable right before paying. The two summary flags are derived from the lines so a client does not have to walk them to know whether to warn the buyer.
