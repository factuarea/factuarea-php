# AccountClaimToken

A voucher that hands ONE NIF of an account over to another account. Issuing one is already giving away control of that NIF: whoever redeems the secret gets the NIF, and taking it back requires the OTHER party to act. The plaintext secret is NOT part of this representation and cannot be: only its irreversible fingerprint is stored, so no later read can return it.
