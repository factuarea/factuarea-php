# StorefrontProductPresentation

One commercial presentation of an item: the format it is sold in (a case of twelve, a five-litre drum, loose weight). It is what decides the unit a price refers to, which is why it travels with its unit code and its conversion: without them a shop window cannot tell "€ per litre" from "€ per drum".
