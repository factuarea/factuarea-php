# BulkCreatePurchaseOrdersRequest

Create purchase orders in bulk. `purchase_orders[]` holds up to 100 payloads, each with the same shape as the single-create body. Row-level problems — a malformed payload, a supplier, product, variant, offer or warehouse that is unknown or of another company, or a `supplier_order_reference` already taken — are reported per row under `failures[]` with the position of the payload that failed, instead of failing the whole batch. That reference is unique per COMPANY, so two rows of the SAME batch that repeat it collide with each other too, and the second one is rejected rather than updating the order the first one created. No order of the batch consumes monthly plan quota: buying has no monthly allowance.
