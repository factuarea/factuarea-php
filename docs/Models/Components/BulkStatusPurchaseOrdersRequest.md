# BulkStatusPurchaseOrdersRequest

Move several purchase orders to the same target status in one request, up to 100 per batch. `ids` is an array of purchase-order UUIDs and `new_status` admits exactly `sent`, `confirmed` and `cancelled`. Those three are the only targets: `draft` is the initial status and has no incoming transition; the three consumption values (`partially_received`, `received` and `billed`) are derived from posted goods receipts and from the supplier-invoice match, and are never requested; and CLOSING an order is not a status at all, it is a separate operation on a single order. Every transition passes the document state guard, and orders that cannot make it are returned under `failures[]` while the rest are applied.
