# FindPurchaseOrderBySupplierReferenceRequest

Look up a purchase order by the reference the supplier uses for it in its own system. `supplier_order_reference` is required, at most 120 characters, and unique per company. An unknown reference — or one that belongs to another company — returns not found, with no difference between the two cases. An order created without a supplier reference is not reachable through this operation.
