# Buyer

Identity of the buyer frozen on the order. `tax_id` is OPTIONAL on purpose: a private individual can place an order without one, which is also why converting that order into a COMPLETE invoice is rejected until the identity is filled in. The order accepts what the invoice cannot. On write the same fields travel FLAT, one level up: the asymmetry is deliberate and documented on both sides.


## Fields

| Field                                                                                                                 | Type                                                                                                                  | Required                                                                                                              | Description                                                                                                           |
| --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `name`                                                                                                                | *string*                                                                                                              | :heavy_check_mark:                                                                                                    | Name or company name of the buyer.                                                                                    |
| `email`                                                                                                               | *string*                                                                                                              | :heavy_check_mark:                                                                                                    | Contact email of the buyer, or `null` when not reported.                                                              |
| `phone`                                                                                                               | *string*                                                                                                              | :heavy_check_mark:                                                                                                    | Contact phone of the buyer, or `null` when not reported.                                                              |
| `taxId`                                                                                                               | *string*                                                                                                              | :heavy_check_mark:                                                                                                    | Spanish fiscal identifier (NIF, CIF or NIE) of the buyer, or `null` for a private individual who did not provide one. |
