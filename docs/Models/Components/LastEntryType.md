# LastEntryType

Type of the last event of the open span; `null` if the workday has not started.


## Values

| Name         | Value        |
| ------------ | ------------ |
| `ClockIn`    | clock_in     |
| `PauseStart` | pause_start  |
| `PauseEnd`   | pause_end    |
| `ClockOut`   | clock_out    |
