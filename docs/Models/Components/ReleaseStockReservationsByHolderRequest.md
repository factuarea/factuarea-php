# ReleaseStockReservationsByHolderRequest

Release everything a holder still keeps on hold, in a single call. Required: `holder_type` and `holder_id`, exactly the pair used when the stock was held. The response reports how many reservations were actually released; repeating the call for a holder that no longer holds anything succeeds with a count of zero. The operation is irreversible — released is a terminal state — and requires an idempotency key when the policy of your credential demands it.
