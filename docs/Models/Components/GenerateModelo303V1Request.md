# GenerateModelo303V1Request

Generate Modelo 303 (VAT self-assessment). `format` defaults to `pdf` when omitted; allowed values are `txt_aeat`, `pdf` and `excel` (only `txt_aeat` is directly submittable on the AEAT portal). `year` and `quarter` are validated for range and the 303 period rules, returning 422 on a violation.
