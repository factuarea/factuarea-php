# AutomationRuleStatus

State of the automation: `draft` (not listening yet), `active` (listening) or `paused` (not listening; either paused by a person or auto-paused by the platform after a streak of failures).


## Values

| Name     | Value    |
| -------- | -------- |
| `Draft`  | draft    |
| `Active` | active   |
| `Paused` | paused   |
