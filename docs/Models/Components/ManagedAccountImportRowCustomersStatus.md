# ManagedAccountImportRowCustomersStatus

Status of the customers of `customers_file` for this row: `none` (no customers for it), `queued` (queued for import into its tax ID) or `blocked` (reason in `customers_code`).


## Values

| Name      | Value     |
| --------- | --------- |
| `None`    | none      |
| `Queued`  | queued    |
| `Blocked` | blocked   |
