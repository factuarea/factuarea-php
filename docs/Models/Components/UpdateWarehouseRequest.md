# UpdateWarehouseRequest

Partially update a warehouse. Every field is optional and an empty body is a no-op, not an error; omitted fields keep their current value and a field that is sent may not be empty. Sending `address` replaces the WHOLE address: `line1`, `city`, `province`, `postal_code` and `country` are required inside the block and omitting `line2` clears it. A new `code` keeps the same uniqueness rule as creation (live warehouses of the same company, 422 pointing at `code`) and never collides with the warehouse being edited. The archived status and the default-warehouse flag are not accepted here: each has its own operation.
