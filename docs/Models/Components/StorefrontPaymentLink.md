# StorefrontPaymentLink

The payment link issued for an order: where to send the buyer, until when it works and whether the effect was simulated. Asking twice for the link of the same order does NOT create two payment sessions while the first one is still live: the second call returns the same address. The identifier of the gateway session is deliberately NOT published — the storefront receives it from the gateway itself on the return, and putting it in a body the browser stores would publish exactly what legitimises confirming a collection.
