# PackSeo

Search engine texts, already resolved: when the pack has no own SEO title or description they fall back to its `name` and `summary`.


## Fields

| Field                           | Type                            | Required                        | Description                     |
| ------------------------------- | ------------------------------- | ------------------------------- | ------------------------------- |
| `title`                         | *string*                        | :heavy_check_mark:              | Title for search engines.       |
| `description`                   | *string*                        | :heavy_check_mark:              | Description for search engines. |
