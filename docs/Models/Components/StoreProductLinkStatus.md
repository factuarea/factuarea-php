# StoreProductLinkStatus

State of the link: `linked` (paired both ways), `pending` (claimed, waiting for the remote identity) and `conflict` (the pairing is ambiguous and a person has to settle it).


## Values

| Name       | Value      |
| ---------- | ---------- |
| `Linked`   | linked     |
| `Pending`  | pending    |
| `Conflict` | conflict   |
