# ReturnStatus

Lifecycle status: `requested` (asked for, and the only status where it can be edited or deleted), `approved` (authorised and numbered), `received` (the goods came back and the stock is booked in), `refunded` (the money was returned, with its corrective invoice) and `rejected` (turned down, terminal).


## Values

| Name        | Value       |
| ----------- | ----------- |
| `Requested` | requested   |
| `Approved`  | approved    |
| `Received`  | received    |
| `Refunded`  | refunded    |
| `Rejected`  | rejected    |
