# ManagedAccountImport

Result of APPLYING a bulk import: every applicable row applied on its own (a row that fails does not undo the others), the statistics of the execution and, for every new live `managed_account` row, its claim voucher. The voucher (`claim_token`, `claim_url`) is returned ONCE, in this response only; it is `null` in every other row, when the link was emailed to the holder (`send_email: true`), for a test import and in an idempotent replay.
