# TaxTotals

Aggregated totals of a set of lines. Returned by `POST /v1/companies/{company}/taxes/calculate-totals`. Total formula: `subtotal + total_vat + total_surcharge − total_retention`.


## Fields

| Field                                                                       | Type                                                                        | Required                                                                    | Description                                                                 | Example                                                                     |
| --------------------------------------------------------------------------- | --------------------------------------------------------------------------- | --------------------------------------------------------------------------- | --------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `subtotal`                                                                  | *string*                                                                    | :heavy_check_mark:                                                          | Sum of the taxable bases of all lines (EUR), as a 2-decimal string.         | 250.00                                                                      |
| `totalVat`                                                                  | *string*                                                                    | :heavy_check_mark:                                                          | Sum of the VAT of all lines, as a 2-decimal string.                         | 52.50                                                                       |
| `totalSurcharge`                                                            | *string*                                                                    | :heavy_check_mark:                                                          | Sum of the equivalence surcharge of all lines, as a 2-decimal string.       | 0.00                                                                        |
| `totalRetention`                                                            | *string*                                                                    | :heavy_check_mark:                                                          | Sum of the withholding (IRPF) of all lines, as a 2-decimal string.          | 15.00                                                                       |
| `total`                                                                     | *string*                                                                    | :heavy_check_mark:                                                          | Grand total, as a 2-decimal string.                                         | 287.50                                                                      |
| `lines`                                                                     | array<[Components\TaxTotalsLine](../../Models/Components/TaxTotalsLine.md)> | :heavy_check_mark:                                                          | Calculated breakdown for each received line, in the same order.             |                                                                             |
