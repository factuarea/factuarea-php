# AccountInvitationWithSecretStatus

Derived state. `accepted` and `revoked` are final; `expired` only applies to an invitation that was still pending when its expiry passed.


## Values

| Name       | Value      |
| ---------- | ---------- |
| `Pending`  | pending    |
| `Accepted` | accepted   |
| `Revoked`  | revoked    |
| `Expired`  | expired    |
