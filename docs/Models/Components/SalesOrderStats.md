# SalesOrderStats

Aggregated headline figures of the sales orders of the authenticated company, narrowed to the date range of the query when one is given. Returned by `GET /v1/companies/{company}/sales-orders/stats`, wrapped in `{ "data": SalesOrderStats }`.
