# ManagedAccountImportV1Request

Multipart body (`multipart/form-data`) of the bulk import, shared by its preview and its application: the accounts file, the optional customers file and the `options`. Both files are CSV in UTF-8 (a BOM is accepted), separated by commas, semicolons or tabs, with up to 20 lines of preamble before the header row, and up to 5 MB each. Size and row limits are checked before reading any row: 413 `import_file_too_large`, 422 `import_row_limit_exceeded`, and 422 `import_file_invalid` for an unreadable file or a missing column.
