# FindWarehouseByCodeRequest

Look up a warehouse by its CODE instead of by its public ID. The body carries ONE property, `code`: the short code of the warehouse, 1 to 20 characters, unique per company among the live ones. It travels in the body and not in the URL because a code may carry characters that would break a path segment. It is matched trimmed and upper-cased, so the case you send does not matter, and only among the LIVE warehouses of the company in the path: an ARCHIVED warehouse is not found by its code, because archiving frees the code for reuse and one code would otherwise resolve to two warehouses. A code nobody uses and a code held by another company answer the same, not found, with no way to tell them apart. It changes nothing: repeating it has no effect and consumes no idempotency key.
