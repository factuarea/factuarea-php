# GenerateModelo130V1Request

Generate Modelo 130 (IRPF instalment payment, direct estimation). `format` defaults to `pdf` when omitted; allowed values are `txt_aeat`, `pdf` and `excel` (only `txt_aeat` is directly submittable on the AEAT portal). `year` and `quarter` are validated for range and the model period rules, returning 422 on a violation.
