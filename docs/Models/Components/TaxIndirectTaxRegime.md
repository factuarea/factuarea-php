# TaxIndirectTaxRegime

Indirect tax regime DERIVED from the AEAT zone, read-only: `iva` (Península), `igic` (Canarias), `ipsi` (Ceuta/Melilla). Only set for `type=vat`; `null` otherwise.


## Values

| Name   | Value  |
| ------ | ------ |
| `Iva`  | iva    |
| `Igic` | igic   |
| `Ipsi` | ipsi   |
