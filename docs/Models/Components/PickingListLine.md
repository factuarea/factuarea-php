# PickingListLine

One line of a picking list: ONE item to take out of the warehouse, with the SNAPSHOT of the description and of the product the line was created with. The snapshot is the point: editing the delivery note afterwards does not rewrite what the warehouse was told to pick, it marks the list as stale.
