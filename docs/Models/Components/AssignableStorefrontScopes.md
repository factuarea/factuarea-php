# AssignableStorefrontScopes

Catalog of the permissions a publishable credential CAN carry, each with its readable label (`{ data }`). It is what a merchant reads before issuing or updating one, so the permission can be offered by name instead of forcing anyone to know the codes. It contains EXCLUSIVELY the permissions of the buyer lane: the ones that manage credentials, and every other permission of the integration API, are never here because a credential that runs in the browser of a visitor cannot carry them. It does NOT paginate: the set is closed and tiny.
