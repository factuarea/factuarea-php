# AccountClaimTokenWithSecret

The issuance response of a claim token: the five fields of `AccountClaimToken` PLUS the plaintext `secret`. This is the ONLY representation that carries it, and the only time it is ever returned — it is not stored in the clear, so if it is lost the only way forward is to issue another token.
