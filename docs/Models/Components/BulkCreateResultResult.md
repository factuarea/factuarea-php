# BulkCreateResultResult

Classification of a single new row of the batch, identified by its 0-based `index`.


## Fields

| Field                                                                                                                | Type                                                                                                                 | Required                                                                                                             | Description                                                                                                          |
| -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `index`                                                                                                              | *int*                                                                                                                | :heavy_check_mark:                                                                                                   | 0-based position of the row within the batch.                                                                        |
| `status`                                                                                                             | *string*                                                                                                             | :heavy_check_mark:                                                                                                   | Row status: `valid` (would be created without error) or `invalid` (has blocking errors).                             |
| `errors`                                                                                                             | array<[Components\FieldIssue](../../Models/Components/FieldIssue.md)>                                                | :heavy_check_mark:                                                                                                   | Per-field blocking issues of the row. Empty when the row is valid.                                                   |
| `warnings`                                                                                                           | array<[Components\FieldIssue](../../Models/Components/FieldIssue.md)>                                                | :heavy_check_mark:                                                                                                   | Per-field non-blocking warnings of the row (e.g. recipient not found in the AEAT census). Empty when there are none. |
