# ExportInvoicesExcelV1RequestStatus

Invoice status to filter by (`draft`, `scheduled`, `issued`, `paid`, `cancelled`, `overdue`, `annulled`). `sent` is accepted as an alias of `issued` in every API version.


## Values

| Name        | Value       |
| ----------- | ----------- |
| `Draft`     | draft       |
| `Scheduled` | scheduled   |
| `Issued`    | issued      |
| `Paid`      | paid        |
| `Cancelled` | cancelled   |
| `Overdue`   | overdue     |
| `Annulled`  | annulled    |
