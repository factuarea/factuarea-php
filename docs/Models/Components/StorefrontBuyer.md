# StorefrontBuyer

Identity of the buyer, the same shape on the cart and on the order it becomes. The fiscal identifier is OPTIONAL and its key is ABSENT —not `null`— when there is none: a private individual without one is not a buyer with an empty field, it is a buyer this lane does not ask it of, and without it the order is born with no commercial contact attached. Neither the IP of the buyer nor any browser tracking identifier is published or stored anywhere in this lane.
