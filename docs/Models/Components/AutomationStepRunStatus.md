# AutomationStepRunStatus

State of the step: `pending`, `running`, `succeeded`, `failed`, `skipped`, `dead_lettered` (parked awaiting a manual replay) or `blocked` (stopped by a guardrail).


## Values

| Name           | Value          |
| -------------- | -------------- |
| `Pending`      | pending        |
| `Running`      | running        |
| `Succeeded`    | succeeded      |
| `Failed`       | failed         |
| `Skipped`      | skipped        |
| `DeadLettered` | dead_lettered  |
| `Blocked`      | blocked        |
