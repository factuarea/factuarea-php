# WorkState

Derived workday state from the ledger: `working`, `paused`, `finished` (clocked out) or `away` (no open workday).


## Values

| Name       | Value      |
| ---------- | ---------- |
| `Working`  | working    |
| `Paused`   | paused     |
| `Finished` | finished   |
| `Away`     | away       |
