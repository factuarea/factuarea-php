# BulkStatusGoodsReceiptsRequest

Move several goods receipts to the same target status in one request. `new_status` admits exactly `posted` and `cancelled`: `created` is the initial status and has no incoming transition. The batch is applied item by item and returns a partial result — a receipt that does not admit the requested transition is reported as a failed item with its reason while the rest are applied — and it is capped at 100 items per request.
