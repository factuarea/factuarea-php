# CreatePromotionV1Request

Schedule a promotion. Required: `name`, `starts_on`, `ends_on`, `channels` and `items`. If any item is rejected, nothing is created.

| `label`                                                                                                          | *?string*                                                                                                        | :heavy_minus_sign:                                                                                               | Text the web shows next to the price. `null` clears it.                                                          |
| `startsOn`                                                                                                       | [\DateTime](https://www.php.net/manual/en/class.datetime.php)                                                    | :heavy_check_mark:                                                                                               | First day (`YYYY-MM-DD`, company time zone). A promotion that starts today or earlier is active at once.         |

It cannot be before `starts_on`. An active promotion accepts only this field. |
