# PackSeparately

What the components would cost bought one by one at their own prices, the reference to measure the saving against.


## Fields

| Field                                    | Type                                     | Required                                 | Description                              |
| ---------------------------------------- | ---------------------------------------- | ---------------------------------------- | ---------------------------------------- |
| `net`                                    | *string*                                 | :heavy_check_mark:                       | Sum of the component prices without VAT. |
| `gross`                                  | *string*                                 | :heavy_check_mark:                       | Sum of the component prices with VAT.    |
