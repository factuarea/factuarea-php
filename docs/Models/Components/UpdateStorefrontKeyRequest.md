# UpdateStorefrontKeyRequest

Partial update of a live publishable storefront credential. All three editable fields are optional: an omitted key keeps its current value and never clears it. `allowed_origins` and `scopes` REPLACE the current list rather than adding to it, and when present they follow exactly the same rules as on creation (non-empty, at most 10 origins, same origin format with no wildcards, buyer-lane scopes only). An empty body `{}` is accepted as a no-op and returns the credential unchanged. `expires_at`, status, prefix and secret are not accepted here: expiry is fixed at issuance, the status only changes through revocation and the secret only through rotation.
