# StorefrontCatalogSelection

What the buyer has chosen so far, resolved against the catalog: which variant, which presentation and which combination it lands on, what is still missing and whether it can be offered at all. This operation ANSWERS instead of failing — a combination that cannot be offered comes back with its flag in `false` and its reason, and the status is still 200 — because a shop window has to be able to grey out an option, not to handle an error while the buyer is still choosing. The refusal with an error belongs to the operations that CONFIRM.
