# NifTransferWithSecret

The issuance response of a tax ID transfer: the fields of `NifTransfer` PLUS the plaintext `secret`. This is the ONLY representation that carries it, and the only time it is ever returned — it is not stored in the clear, not even in the idempotency cache, so an idempotent replay of the issuance returns `secret: null`. If it is lost, revoke the transfer and issue another one.
