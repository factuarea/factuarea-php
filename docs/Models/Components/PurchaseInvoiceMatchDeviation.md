# PurchaseInvoiceMatchDeviation

ONE reason why a line does not match, with the figure that justifies it. The classification alone is not actionable — "there is a price deviation" can neither be accepted nor argued — so every reason always carries the three magnitudes: the expected one, the invoiced one and the signed difference between them. Tolerance is applied BEFORE classifying, so a reason with a zero difference never travels.
