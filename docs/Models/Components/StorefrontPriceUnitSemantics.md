# StorefrontPriceUnitSemantics

Where the unit amount came from: `per_base_unit` (per base unit of the item) or `per_commercial_unit` (per commercial unit of the presentation). It describes the SOURCE and not the amount, so a shop window can label "€/L" or "€/drum" without recomputing anything.


## Values

| Name                | Value               |
| ------------------- | ------------------- |
| `PerBaseUnit`       | per_base_unit       |
| `PerCommercialUnit` | per_commercial_unit |
