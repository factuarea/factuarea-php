# ReorderSuggestion

One line of the replenishment report: a catalog item below its reorder point, with the quantity it would be worth buying and the supplier offer that quantity comes from. Returned by `GET /v1/companies/{company}/purchase-reorder-suggestions` inside `{ "data": [ReorderSuggestion, …], "actionable_count": …, "not_actionable_count": … }`. It is a COMPUTED report and not a stored collection: it is recalculated on every call, it is not paginated, and its size grows with the catalog.
