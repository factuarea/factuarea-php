# ManagedAccountImportV1RequestOptions

Options of the import, sent as form fields (`options[send_email]=true`) or as one JSON field. Only the three below are accepted, all `false` by default; any other key is rejected with 422.


## Fields

| Field                                                                                                                                                                               | Type                                                                                                                                                                                | Required                                                                                                                                                                            | Description                                                                                                                                                                         |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sendEmail`                                                                                                                                                                         | *?bool*                                                                                                                                                                             | :heavy_minus_sign:                                                                                                                                                                  | Email the claim link to the holder of every new managed account (`true`) instead of returning the voucher once in the response (`false`, default).                                  |
| `applyCustomersToOwnCompany`                                                                                                                                                        | *?bool*                                                                                                                                                                             | :heavy_minus_sign:                                                                                                                                                                  | Import the customers without `account_ref` into your own company in focus (the only tax ID of the credential scope, or the only tax ID of your account). Requires `contacts:write`. |
| `confirmPlanChanges`                                                                                                                                                                | *?bool*                                                                                                                                                                             | :heavy_minus_sign:                                                                                                                                                                  | Apply the plan changes that rows ask for existing managed accounts your account pays. Without it those rows are `WARNING` and the plan does not change.                             |
