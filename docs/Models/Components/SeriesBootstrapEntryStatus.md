# SeriesBootstrapEntryStatus

`created`: the type had no active series and its default one was created. `existing`: it already had a default series and nothing was touched. `no_default`: it has active series but none marked as default — nothing was created and nothing was promoted.


## Values

| Name        | Value       |
| ----------- | ----------- |
| `Created`   | created     |
| `Existing`  | existing    |
| `NoDefault` | no_default  |
