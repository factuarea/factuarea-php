# EntryType

Type of clock event: `clock_in` (opens a work span), `pause_start`, `pause_end` or `clock_out` (closes the span).


## Values

| Name         | Value        |
| ------------ | ------------ |
| `ClockIn`    | clock_in     |
| `PauseStart` | pause_start  |
| `PauseEnd`   | pause_end    |
| `ClockOut`   | clock_out    |
