# StockReservation

A stock reservation: units of an item held for a HOLDER —a cart, an order, whatever the integration calls it— so that nobody else can sell them while that holder decides. It is what lets a bespoke storefront hold goods without inventing its own set-aside table. It does NOT move the ledger: a held reservation lowers the AVAILABLE quantity and leaves the physical balance untouched.
