# StorefrontCategory

One category of the shop window, with how many publishable items carry it. It is the classification the merchant already uses on the catalog, published with a stable identifier so a shop window can build a menu out of it and filter the listing with the same value it rendered. The count only counts PUBLISHABLE items: a category whose items are all withdrawn publishes zero, and that is the honest answer.
