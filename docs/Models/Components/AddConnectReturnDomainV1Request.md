# AddConnectReturnDomainV1Request

Register a return domain of your account. `domain` is required: the host only (up to 253 characters), without scheme, port or path; it is lower-cased and normalized, wildcards are rejected, and a host that is not a valid public name returns 422 `business_rule_violation` with subcode `invalid_return_domain`. Any other key in the body or the query returns 400 `parameter_unknown`.
