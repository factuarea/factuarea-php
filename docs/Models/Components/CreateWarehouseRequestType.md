# CreateWarehouseRequestType

Operational nature of the warehouse: `own` (a site of your own company), `external` (a third-party site, such as a logistics operator), `store` (a point of sale) or `transit` (goods on their way between two warehouses). It describes what the warehouse IS, and no operation derives from it: a transfer may run between any two of them.


## Values

| Name       | Value      |
| ---------- | ---------- |
| `Own`      | own        |
| `External` | external   |
| `Store`    | store      |
| `Transit`  | transit    |
