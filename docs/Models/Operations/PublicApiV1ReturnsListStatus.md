# PublicApiV1ReturnsListStatus

Return status. Five published values: `requested` (asked for and awaiting a decision), `approved` (accepted and numbered), `received` (the goods came back in), `refunded` (the money went back, the end of the road) and `rejected` (turned down, also terminal). Exact match on `status`.


## Values

| Name        | Value       |
| ----------- | ----------- |
| `Requested` | requested   |
| `Approved`  | approved    |
| `Received`  | received    |
| `Refunded`  | refunded    |
| `Rejected`  | rejected    |
