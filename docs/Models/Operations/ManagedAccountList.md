# ManagedAccountList

Cursor-paginated list of your managed accounts in the environment of the key (`{ data, has_more, next_cursor }`). Without `status` it lists only the managements in force; with `status=ended` each item is an `EndedManagedAccount`. No item carries a claim voucher.
