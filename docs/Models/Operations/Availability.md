# Availability

Only offers with this availability: `available`, `unavailable`, `unknown`, `seasonal` or `store_dependent`.


## Values

| Name             | Value            |
| ---------------- | ---------------- |
| `Available`      | available        |
| `Unavailable`    | unavailable      |
| `Unknown`        | unknown          |
| `Seasonal`       | seasonal         |
| `StoreDependent` | store_dependent  |
