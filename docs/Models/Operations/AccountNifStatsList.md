# AccountNifStatsList

Invoicing statistics of every company (tax ID) your credential reads in the account (`{ data, has_more, next_cursor }`). Not paginated: an account holds a bounded set of companies, so `has_more` is always `false` and `next_cursor` always `null`.


## Fields

| Field                                                                                                           | Type                                                                                                            | Required                                                                                                        | Description                                                                                                     | Example                                                                                                         |
| --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `data`                                                                                                          | array<[Components\CompanyStats](../../Models/Components/CompanyStats.md)>                                       | :heavy_check_mark:                                                                                              | One row per company of the account your credential reads (active and inactive; archived ones are not included). |                                                                                                                 |
| `hasMore`                                                                                                       | *bool*                                                                                                          | :heavy_check_mark:                                                                                              | Always `false`: the whole list is returned in one response.                                                     | false                                                                                                           |
| `nextCursor`                                                                                                    | *string*                                                                                                        | :heavy_check_mark:                                                                                              | Always `null`: there is no next page.                                                                           | null                                                                                                            |
