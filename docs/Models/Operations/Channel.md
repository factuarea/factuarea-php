# Channel

Origin channel of the order, fixed when it is created and changed by no later operation. Seven published values: `manual` (entered by a person), `store` (a connected e-commerce store), `storefront` (your own public storefront), `api` (this API), `quote` and `proforma` (converted from one of those documents) and `assistant` (created through the conversational assistant). Exact match on `channel`.


## Values

| Name         | Value        |
| ------------ | ------------ |
| `Manual`     | manual       |
| `Store`      | store        |
| `Storefront` | storefront   |
| `Api`        | api          |
| `Quote`      | quote        |
| `Proforma`   | proforma     |
| `Assistant`  | assistant    |
