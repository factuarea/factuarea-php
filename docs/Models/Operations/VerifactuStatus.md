# VerifactuStatus

VeriFactu status of the invoice: `no_verifactu` (no VeriFactu record), `pending` (queued or submitted to the AEAT), `accepted` or `rejected` (rejected or failed).


## Values

| Name          | Value         |
| ------------- | ------------- |
| `NoVerifactu` | no_verifactu  |
| `Pending`     | pending       |
| `Accepted`    | accepted      |
| `Rejected`    | rejected      |
