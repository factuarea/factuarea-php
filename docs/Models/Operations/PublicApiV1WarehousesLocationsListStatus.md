# PublicApiV1WarehousesLocationsListStatus

Location status: `active` (in use) or `archived` (withdrawn). Unfiltered, the listing returns BOTH: an archived location still explains where goods used to sit. Exact match on `status`.


## Values

| Name       | Value      |
| ---------- | ---------- |
| `Active`   | active     |
| `Archived` | archived   |
