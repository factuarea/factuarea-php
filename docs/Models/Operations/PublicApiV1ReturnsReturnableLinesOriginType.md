# PublicApiV1ReturnsReturnableLinesOriginType

Kind of document the goods went out on: `delivery_note`, `invoice` or `sales_order`. Required, and it is not redundant with the identifier: the three kinds are numbered independently, so the identifier alone does not say which document to read the delivered quantities from.


## Values

| Name           | Value          |
| -------------- | -------------- |
| `DeliveryNote` | delivery_note  |
| `Invoice`      | invoice        |
| `SalesOrder`   | sales_order    |
