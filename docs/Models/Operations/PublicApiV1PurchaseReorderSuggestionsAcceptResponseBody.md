                                                                                                                                                                                                    | Result of accepting a replenishment suggestion: the partial-success counters shared by every bulk endpoint of this API, plus the purchase orders that were created — one per SUPPLIER, grouped server-side. Returned by `POST /v1/companies/{company}/purchase-reorder-suggestions/accept`. The orders are created as DRAFTS, so nothing was sent to any supplier and the operation is not irreversible; what it is NOT is idempotent by itself: accepting the same proposal twice creates a SECOND set of drafts, because a suggestion is not a document with an identity. Send an `Idempotency-Key` when you retry. |
