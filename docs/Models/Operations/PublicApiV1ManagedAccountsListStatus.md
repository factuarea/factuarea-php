# PublicApiV1ManagedAccountsListStatus

Status filter: `provisioned`, `claimed` or `active` (status of the account), or `ended` (items carry only `id`, `external_ref` and `management`). Without it, only the managements in force.


## Values

| Name          | Value         |
| ------------- | ------------- |
| `Provisioned` | provisioned   |
| `Claimed`     | claimed       |
| `Active`      | active        |
| `Ended`       | ended         |
