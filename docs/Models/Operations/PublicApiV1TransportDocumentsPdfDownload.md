# PublicApiV1TransportDocumentsPdfDownload

Pass `1` (or `true`) to receive the PDF with `Content-Disposition: attachment`; otherwise it is served `inline`.


## Values

| Name    | Value   |
| ------- | ------- |
| `Zero`  | 0       |
| `One`   | 1       |
| `True`  | true    |
| `False` | false   |
