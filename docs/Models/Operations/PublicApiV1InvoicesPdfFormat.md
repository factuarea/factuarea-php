# PublicApiV1InvoicesPdfFormat

Paper of the PDF: `a4` (default), `ticket_80` (80 mm thermal roll) or `ticket_58` (58 mm roll); each format has its own `ETag`.


## Values

| Name       | Value      |
| ---------- | ---------- |
| `A4`       | a4         |
| `Ticket80` | ticket_80  |
| `Ticket58` | ticket_58  |
