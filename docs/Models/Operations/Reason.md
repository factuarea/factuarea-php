# Reason

Header reason of the return, out of a closed set of four. When it was not stated on the request it is derived from the lines, so every return carries one and this filter never leaves one out for lack of a value. Exact match on `reason`.


## Values

| Name                  | Value                 |
| --------------------- | --------------------- |
| `MerchandiseReturned` | merchandise_returned  |
| `OrderCancelled`      | order_cancelled       |
| `CustomerRequest`     | customer_request      |
| `ProductDefective`    | product_defective     |
