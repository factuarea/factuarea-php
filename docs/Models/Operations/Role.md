# Role

Role to remove: `customer`, `supplier` or `lead`. It is always read from the `{role}` path segment, so you do not need to repeat it here; a value sent as a query parameter is ignored.


## Values

| Name       | Value      |
| ---------- | ---------- |
| `Customer` | customer   |
| `Supplier` | supplier   |
| `Lead`     | lead       |
