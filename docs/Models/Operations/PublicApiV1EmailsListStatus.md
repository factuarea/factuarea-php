# PublicApiV1EmailsListStatus

Delivery status to filter by (queued, sending, sent, failed). Reflects hand-off to the outgoing SMTP server, not real inbox delivery.


## Values

| Name      | Value     |
| --------- | --------- |
| `Queued`  | queued    |
| `Sending` | sending   |
| `Sent`    | sent      |
| `Failed`  | failed    |
