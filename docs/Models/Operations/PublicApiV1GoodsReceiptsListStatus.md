# PublicApiV1GoodsReceiptsListStatus

Goods receipt status. `created` is the receipt as written down, with no effect yet; `posted` is the accounted one — the only status that consumes pending quantity from the purchase order; `cancelled` no longer counts. Exact match on `status`.


## Values

| Name        | Value       |
| ----------- | ----------- |
| `Created`   | created     |
| `Posted`    | posted      |
| `Cancelled` | cancelled   |
