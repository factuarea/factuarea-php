# PublicApiV1StockReservationsListStatus

Reservation status: `held` (the goods are on hold and do not count as available), `released` (the hold was undone and the goods are available again) and `consumed` (the hold ended by turning into a real movement). The last two are terminal. Exact match on `status`.


## Values

| Name       | Value      |
| ---------- | ---------- |
| `Held`     | held       |
| `Released` | released   |
| `Consumed` | consumed   |
