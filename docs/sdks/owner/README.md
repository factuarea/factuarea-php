# Account.Owner

## Overview

### Available Operations

* [publicApiV1AccountOwnerTransfer](#publicapiv1accountownertransfer) - Transfer account ownership

## publicApiV1AccountOwnerTransfer

Put the ACCOUNT in the name of another person of the team. Requires the `account:owner` scope — the highest privilege of the account — and the caller must be the CURRENT owner, checked per request against the source of truth: a credential outlives its creator ceasing to be the owner, so the check is never frozen at issuance. Pass the target person in `owner_user_id`; the account subject and the acting person come from the authenticated credential and never from the body. The 200 publishes the incoming AND the outgoing owner, which no later read can reconstruct. Returns 403 `owner_transfer_forbidden` when the caller is not the current owner (it reveals neither who is nor whether the target exists), 422 `invalid_param_value` when `owner_user_id` is missing or malformed, 422 `business_rule_violation` when the target does not exist or is not a member of any tax ID of the account (both with the SAME body), 422 `idempotency_key_required` because the operation is irreversible, and 404 `account_not_found` when `{account}` is not the credential account — foreign, non-existent or malformed, all three with the same body and never a 403.
