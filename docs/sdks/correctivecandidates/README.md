# Returns.CorrectiveCandidates

## Overview

### Available Operations

* [publicApiV1ReturnsCorrectiveCandidatesList](#publicapiv1returnscorrectivecandidateslist) - List the corrective invoice candidates of a return

## publicApiV1ReturnsCorrectiveCandidatesList

List the invoices that this return could correct, each one with its public id, its number, its total and its issue date. It is the question to ask right before refunding: when the origin of a return resolves to more than one invoice, the refund cannot choose for you and is rejected asking you to name one, and this read is what gives you the identifiers to choose from. The internal identifier of a candidate is never published. A return with no candidates answers with an empty list and not with an error — the empty collection is the correct answer to a legitimate question, and the rejection belongs to the refund. A return of another company answers as not found.
