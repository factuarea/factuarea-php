## publicApiV1AdditionalNifSeatsStatus

Return the contracted seats of the additional tax IDs of the account: `quantity` billed, `max_additional_nifs` and the `seats` block (contracted, occupied, free, pending reduction).
- `subscribed: false` means no seat subscription is alive; `seats_billable: false` is a legitimate no-charge state (trial, exempt).
- Needs `companies:read`; 403 `forbidden_action` when the credential does not reach the account owner.

## publicApiV1AdditionalNifSeatsUpdate

Set the contracted additional tax ID seats of the account to an absolute `contracted_seats`.
- A higher value buys the missing seats now (402 `payment_method_required` or `additional_nif_charge_failed` buys nothing); a lower one is a reduction applied at renewal, without refund.
- Going below the occupied seats needs `deactivate` with exactly the surplus (422 `contracted_seats_selection_required`); breaking an offer package needs `accept_offer_package_loss`.
- `Idempotency-Key` is mandatory. Above the cap: 422 `additional_nif_limit_reached`.

## publicApiV1AdditionalNifSeatsPreview

Preview, without charging or writing, setting the contracted additional tax ID seats to `contracted_seats`.
- A purchase returns the amount charged today; a reduction returns `0.00`, the `pending_reduction`, `deactivations_required` and the `offer_package_loss`.
- Amounts are 2-decimal euro strings; above the account cap it returns 422 `additional_nif_limit_reached`.
- 403 `billing_managed_by_provider` when the provider manages billing.
