# Storefront.Products.ProductOptions

## Overview

### Available Operations

* [publicApiV1StorefrontProductsOptionsList](#publicapiv1storefrontproductsoptionslist) - List the options of a storefront product

## publicApiV1StorefrontProductsOptionsList

List the option groups of a publishable article with their values, which is what a storefront needs to render a configurator: every group carries its public id, its name, whether it is required and its position, and every value its public id, its label, its position and the price adjustment it applies. It is authenticated with the publishable storefront key that travels in the browser of an anonymous shopper. A group scoped to a variant or to a presentation that is not publishable is dropped WHOLE and not partially, so the configurator never offers a path that cannot be bought. Which combination of values can actually be offered is not decided here: ask the catalog-selection resolution before pricing it.
