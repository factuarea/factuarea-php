# Storefront.Categories

## Overview

### Available Operations

* [publicApiV1StorefrontCategoriesList](#publicapiv1storefrontcategorieslist) - List storefront categories

## publicApiV1StorefrontCategoriesList

List the categories the publishable catalog of your company uses, each one with its public id, its name and how many publishable articles it holds. It is authenticated with the publishable storefront key that travels in the browser of an anonymous shopper. The categories of the storefront are the TAGS of your catalog: there is no separate tree to maintain, the public id is a stable slug derived from the tag, and that id is exactly the value the catalog listing takes in its category filter. A tag with no publishable article behind it is not listed.
