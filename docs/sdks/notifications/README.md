# Notifications

## Overview

### Available Operations

* [publicApiV1NotificationsList](#publicapiv1notificationslist) - List notifications
* [publicApiV1NotificationsMarkAllRead](#publicapiv1notificationsmarkallread) - Mark all notifications as read
* [publicApiV1NotificationsRead](#publicapiv1notificationsread) - Mark a notification as read

## publicApiV1NotificationsList

List the in-app notifications of the member who owns the API key, newest first. Filter by `status` (`unread` or `read`) and `category`; archived notifications never appear. Cursor-paginated: pass the `next_cursor` of a page as `starting_after` to get the next one; `has_more` tells whether there are more.

### Example Usage

<!-- UsageSnippet language="php" operationID="public-api.v1.notifications.list" method="get" path="/companies/{company}/notifications" example="success" -->
