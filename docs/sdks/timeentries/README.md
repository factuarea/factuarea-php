# TimeEntries

## Overview

### Available Operations

* [publicApiV1TimeEntriesClockIn](#publicapiv1timeentriesclockin) - Clock in an employee
* [publicApiV1TimeEntriesClockOut](#publicapiv1timeentriesclockout) - Clock out an employee
* [publicApiV1TimeEntriesCurrent](#publicapiv1timeentriescurrent) - Retrieve an employee’s current workday state
* [publicApiV1TimeEntriesList](#publicapiv1timeentrieslist) - List all time entries
* [publicApiV1TimeEntriesPause](#publicapiv1timeentriespause) - Start a pause
* [publicApiV1TimeEntriesManual](#publicapiv1timeentriesmanual) - Record a manual retroactive entry
* [publicApiV1TimeEntriesResume](#publicapiv1timeentriesresume) - Resume from a pause
* [publicApiV1TimeEntriesShow](#publicapiv1timeentriesshow) - Retrieve a time entry

## publicApiV1TimeEntriesClockIn

Clock the start of an employee’s workday, opening a new work span. `employee_id` (UUID v7) and `source` (`web`/`mobile`) are required; `occurred_at` defaults to the server time. Valid only when the employee is not already clocked in; an invalid transition returns 422 in Spanish. Returns 201 with the created `clock_in` entry.

## publicApiV1TimeEntriesList

List the time entries of your company with cursor-based pagination, ordered by `occurred_at`. Supports filtering by `employee_id` (UUID v7), a date range (`from`/`to`) and `entry_type` (`clock_in`/`pause_start`/`pause_end`/`clock_out`).

    ->setSecurity(
        new Components\Security(
            http: '<YOUR_BEARER_TOKEN_HERE>',
        )
    )
    ->build();

$request = new Operations\PublicApiV1TimeEntriesListRequest(
    factuareaVersion: LocalDate::parse('2026-06-01'),
    xActiveProfile: '01931b3e-7c4a-7f2e-9a8b-3c5d6e7f8a0c',
);
