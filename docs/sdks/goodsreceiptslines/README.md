# GoodsReceipts.Lines

## Overview

* [publicApiV1GoodsReceiptsLinesList](#publicapiv1goodsreceiptslineslist) - List the lines of a goods receipt

## publicApiV1GoodsReceiptsLinesList

List the lines of a goods receipt, each one naming by its public id the line of the purchase order it consumes, the article and its variant, the code of the purchase unit and the quantity received both in that unit and in the base unit.
