# Account.NifTransfers

## Overview

### Available Operations

* [publicApiV1AccountNifTransfersAccept](#publicapiv1accountniftransfersaccept) - Accept a tax ID transfer
* [publicApiV1AccountNifTransfersCreate](#publicapiv1accountniftransferscreate) - Issue a tax ID transfer
* [publicApiV1AccountNifTransfersList](#publicapiv1accountniftransferslist) - List issued tax ID transfers
* [publicApiV1AccountNifTransfersRevoke](#publicapiv1accountniftransfersrevoke) - Revoke a tax ID transfer

## publicApiV1AccountNifTransfersAccept

Accept a tax ID transfer with its `secret`: the tax ID moves to the account in the path. Irreversible.
- The body carries only `secret`; requires `Idempotency-Key` (else 422 `idempotency_key_required`).
- Plan gates run first, e.g. 402 `additional_nif_plan_required`, 402 `payment_method_required`.
- 422 `nif_transfer_invalid` for an unusable secret; 422 `nif_transfer_expired`. Requires the `nif_transfers:write` scope, which `*` does not cover: the API key must list it explicitly.

## publicApiV1AccountNifTransfersCreate

Issue a tax ID transfer over ONE tax ID of your account (`company_id`); returns 201 with its plaintext `secret`.
- The secret is shown once and never stored (`null` on replay); requires `Idempotency-Key`.
- Optional `recipient_account_id` restricts who can accept; `expires_at` defaults to 24 hours (max 7 days).
- 403 `forbidden_action`; 404 `profile_not_found`. Requires the `nif_transfers:write` scope, which `*` does not cover: the API key must list it explicitly.

## publicApiV1AccountNifTransfersList

List the tax ID transfers your account has ISSUED, cursor-paginated with `limit` (1-100, default 25).
- Optional `status` filter (`active`, `expired`, `revoked`, `consumed`); invalid returns 422 `invalid_param_value`.
- Limited to tax IDs you reach; received transfers and the `secret` are never listed. Needs `nif_transfers:read`. Requires the `nif_transfers:read` scope, which `*` does not cover: the API key must list it explicitly.

## publicApiV1AccountNifTransfersRevoke

Revoke a tax ID transfer your account issued before anyone accepts it; its secret then no longer moves the tax ID.
- Returns 200 with `status: revoked`; optional `reason` (max 500 characters) goes to the audit trail.
- Irreversible but idempotent; requires `Idempotency-Key`.
- 422 `business_rule_violation` if already accepted; 404 `resource_not_found`. Requires the `nif_transfers:write` scope, which `*` does not cover: the API key must list it explicitly.
