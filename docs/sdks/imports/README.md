# Contacts.Imports

## Overview

### Available Operations

* [publicApiV1ContactsImportsErrors](#publicapiv1contactsimportserrors) - Download contact import errors

## publicApiV1ContactsImportsErrors

Download the authorized UTF-8 CSV report with original row_number, field, code and message. Requires contacts:read. Unknown, foreign-company and non-contact imports or an unavailable report return 404 import_not_found. The MCP download_contact_import_errors tool returns identical bytes as file_base64 with filename, mime_type and SHA-256 hash.

## publicApiV1ContactsImportsShow

Retrieve persisted progress and row outcomes using the UUID returned as import_uuid, including synchronous imports. Requires contacts:read. Unknown, foreign-company and non-contact imports return the same 404 import_not_found. Added counts applied create/update/add_role rows; failed imports retain confirmed progress and unprocessed_count.
